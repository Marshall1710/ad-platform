# Контракт проверки локального стенда

- Кабинет: GET http://localhost:3000/ возвращает HTTP 200 и заголовок «Кабинет рекламодателя».
- Аукцион: GET http://localhost:3001/ возвращает HTTP 200 и заголовок «Тестовый Аукцион».
- DSP: GET http://localhost:8080/health возвращает HTTP 200 и JSON со статусом ok.
- cabinet-db: команда pg_isready внутри контейнера завершается кодом 0 для БД cabinet.
- dsp-db: команда pg_isready внутри контейнера завершается кодом 0 для БД dsp.

Эти адреса служат для проверки каркаса и не определяют будущий bid request API.
