- SC-002: `npm run build` успешно собрал три образа.

Это каркас без бизнес-логики и схем данных. Приложения пока не обращаются к своим БД; отдельность баз и их готовность проверены через Docker Compose. Локальные пароли в `compose.yaml` предназначены только для этого стенда. Секреты окружения в репозиторий не добавлены.
