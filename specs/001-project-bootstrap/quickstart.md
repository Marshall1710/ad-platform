# Проверка локального каркаса

Предусловия: Docker Desktop запущен; Node.js и npm доступны. Для локального Go-тестирования установлен Go 1.27.3.

1. В корне репозитория выполнить `npm ci` и `npx playwright install chromium`.
2. Выполнить `npm run build`; ожидаются три собранных образа.
3. Выполнить `npm run up`; ожидаются три приложения и две готовые БД.
4. Открыть http://localhost:3000/ и http://localhost:3001/; проверить стартовые страницы.
5. Выполнить `npm test`; ожидается успешный smoke-прогон пяти компонентов.
6. Для остановки выполнить `npm run down`; постоянные тома БД сохраняются.

Фактически выполненные команды и их результаты записываются в verification.md.
