# Проверка кампаний и креативов кабинета

Инструкция для проверки после реализации. Нужны Node.js 22 с зависимостями проекта, Docker с доступом к движку и Chromium для Playwright.

## Запустить кабинет

Из корня `ad-platform`:

```powershell
npm run setup:local
docker compose up --build -d cabinet-db cabinet
```

Открыть кабинет по URL из локальной конфигурации. По умолчанию это [http://127.0.0.1:3000](http://127.0.0.1:3000). Для ручной проверки администратора выполнить `npm run admin:create` в интерактивном терминале. Для тестов учётная запись администратора создаётся существующим операторским механизмом на тестовых данных.

## Проверить обе роли

1. Войти как рекламодатель. Создать пустую кампанию и снова открыть её. Проверить, что идентификатор сохранился, а статус — `created`.
2. Задать категорию, модель и ставку. Добавить JPEG или PNG 300×250 с абсолютной ссылкой и пустым названием. Включить с пустыми таргетами. Изменить ставку у активной кампании и убедиться, что статус остался `active`.
3. Войти как администратор. Выбрать этого рекламодателя, открыть его кампанию и поставить на паузу. У владельца она должна отображаться в `paused`. Снова включить её от владельца, затем поставить на паузу и удалить.
4. Убедиться, что другой рекламодатель не может открыть кампанию первого по известному идентификатору и не видит список пользователей.
5. Создать кампанию администратором для выбранного рекламодателя. Проверить доступ владельца и отклонение неверных данных и недопустимых действий.

## Запустить автоматические проверки

```powershell
npm run test:unit
npm run test:integration -- tests/integration/cabinet-campaigns.test.ts tests/integration/cabinet-auth.test.ts
npm run typecheck --workspace=apps/cabinet
npx playwright test tests/e2e/cabinet-campaigns.spec.ts tests/e2e/cabinet-auth.spec.ts
```

Файлы с `cabinet-campaigns` будут добавлены при реализации. Интеграционные тесты используют отдельный PostgreSQL в Testcontainers. Playwright обращается к запущенному кабинету. Результаты и покрытие критериев фиксируются в `verification.md`.
