# Quickstart: первый срез доступа

1. Установить зависимости через `npm ci`; подготовить локальный `.env` с секретом авторизации (команда настройки описывается в README).
2. Поднять стенд `npm run up`; миграция схемы кабинета применяется до старта Next.js.
3. Открыть кабинет, зарегистрировать рекламодателя по email/паролю; убедиться в переходе к заглушке с email и ролью.
4. Обновить страницу, выйти и проверить, что прямое открытие защищённого адреса ведёт на вход.
5. Создать администратора через `npm run admin:create`, войти через общую форму и проверить заглушку с ролью `admin`; списка пользователей нет.
6. Запустить unit, интеграционные и Playwright-проверки через документированные npm-команды; убедиться, что прямой запрос на публичную регистрацию с `role: admin` не повышает роль.
7. Проверить локальный Next Dev, чтобы серверный кабинет подключался к своей БД; DSP и Аукцион остаются без изменений.
